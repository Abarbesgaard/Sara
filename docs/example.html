before you begin — bind the agent

Bind the agent

Install sara, then bind your agent to the law. The simplest way — the Fat Vow — is to paste Legio into your agent's instruction file. Legio is the operating law; the creed is the human mindset and need not ride in context.

$ curl -fsSL https://raw.githubusercontent.com/Abarbesgaard/Sara/main/scripts/install.sh | sh

# then, in your project's AGENTS.md / CLAUDE.md:
#   paste docs/factions/faction-legio.md   (Legio — its Viae + leges)

From here the agent is sub lege machinae. Everything below is what a session then looks like.

the work — a defect arrives

The charge

bug · Via Emendatio

Login rejects names containing an apostrophe

A user named O'Brien cannot log in — the form reports "invalid characters". Repair it.

One defect, one kind of work — Via Emendatio, the rite for repairing a defect. Its Ritus is fixed: reproduce → locate → prove with a failing test → mend → witness → record.

Two ways it begins. You, the operator, can invoke the rite by command — the surest way to pin the agent to exactly this road:

› /via_emendatio Login rejects names containing an apostrophe

Or, if Legio rides always-on (the Fat Vow), the agent recognises the work as a repair and declares the Via itself. Either way the same Ritus is walked and the same Testes gate the ending — the operator simply chooses whether to name the rite or let the agent name it.

1 — recall, then frame the charge

Lex Recordi makes recall come first — never write memory before seeking its duplicate; never re-derive what a past session already learned.

› recall --tag auth --project shop
  m12 [auth] login validation runs through validateName() in src/auth/login.ts

› add "Login rejects apostrophe in names" --tag auth --priority H \
      --check "Reproduce with O'Brien" \
      --check "Prove with a failing test" --check "Mend validateName" \
      --check "Witness: suite green" --kind acceptance
  Created charge (a3f9c1e2): Login rejects apostrophe in names

The charge now carries its own guide — its steps and its acceptance criterion. That guide is the Edictum.

2 — a fork: which file? (Sententia decides)

The agent could stop and ask "which validation file do you mean?". No Lex forbids it, no Edictum names the file, no Mos points the way. So the tie-breaker — a Sententia — speaks: Non Vaga. Take the most specific path already open (the validateName() that recall surfaced) and proceed without asking leave.

3 — walk the Ritus, proving each phase

Lex Cursus fixes the order: no phase begins before its predecessor closes, and none closes but by a step_done that carries evidence.

› next            # → step 1: reproduce with O'Brien
› step_done 1 --result "Confirmed: validateName() rejects ' via /[a-z]/i guard"

› next            # → step 2: prove with a failing test
› step_done 2 --result "Added test 'accepts apostrophe' — RED, as required"

› next            # → step 3: mend
› step_done 3 --result "Widened guard to allow ' - . ; commit b1c2d3e"

4 — witness (Mos supplies the default)

The charge's Edictum says "witness: suite green" but names no command. Where the Edictum is silent, Mos — the documented default — is taken: run the project's configured test command from sara init. No guessing, no asking.

› verify --run
  ✓ npm test — 48 passed (was 47; the new test now GREEN)
› step_done 4 --kind acceptance --result "Full suite green; the failing test passes"

5 — the gate (Lex halts you)

Lex Termini is invariant and cannot be softened. The agent opens a PR and links it — but refuses to call the charge done, because the PR is not yet merged. Opening the road is not walking it.

› git push && gh pr create --fill
› link a3f9c1e2 https://github.com/you/shop/pull/91
› learn --auto-files --tag auth "validateName() must allow ' - . in surnames"

› done a3f9c1e2
  ✗ HALT (Lex Termini): PR #91 is open, not merged. The charge stays.

Once a human merges #91, the same done succeeds. The agent stopped exactly where the law commands — not a step early, not a step late.

the whole hierarchy, in one charge

Where each authority bit

Lexstatute — always
The invariant floor. It fired at recall (Recordi), at ordering the steps (Itineris), and at the gate (Termini).here: halted done until the PR merges.
Edictumthe charge's guide
Binding for this charge only — its own steps and acceptance criteria, set when the charge was framed.here: "prove with a failing test", "witness: suite green".
Mosthe default
The documented custom, taken when nothing above is written.here: the test command came from the project's sara init config.
Sententiathe tie-breaker
A maxim — speaks only at a fork no Lex, Edictum, or Mos settles.here: Non Vaga chose the file instead of asking.

When two would conflict, the higher wins — always. Lex > Edictum > Mos > Sententia. That single ordering is what keeps an agent decisive without ever going rogue.
