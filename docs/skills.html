the six Viae — Legio's kinds of work

A Via is a kind of work. Declare one per charge — it fixes the Ritus (the ordered acts) and the Testes (the witnesses of completion). Click any /command to read its full SKILL.md on GitHub.

/via_genesis

Genesis

build a new capability

Ritus

recall prior art → declare acceptance criteria → build the smallest whole meeting one → witness → record

Testes

every criterion met; build compiles & runs; a test covers the new behaviour

/via_renovatio

Renovatio

improve, behaviour unchanged

Ritus

observe → pin behaviour with a test first → change → witness the pinning tests pass identically → record

Testes

pinning tests exist and pass unchanged; no new behaviour under cover of a refactor

/via_emendatio

Emendatio

repair a defect

Ritus

reproduce → locate → prove with a failing test → mend → witness the test passes and none regress → record the cause

Testes

a test that failed before and passes after; full suite green

/via_exploratio

Exploratio

investigate, no code changed

Ritus

frame one question → gather evidence → draw only evidence-carried conclusions → record findings

Testes

each conclusion cites its sign; question answered or declared unanswerable; no source file changed

/via_validatio

Validatio

write or run verification

Ritus

name what must be proven → write/identify the check → run it and read the true result → record the outcome

Testes

check exists and was run; real result recorded; a failure reported, never buried

/via_publicatio

Publicatio

carry finished work to the gate

Ritus

confirm every Testes green → assemble the record → open + link the PR → halt at the gate

Testes

all prior Testes green; PR opened and linked; nothing done before merge

the rite of adoption — two ways to bind

One law, two vestments. Choose how the faction rides with your agent. Both assume the sara MCP tools are connected.

easiest · works anywhere

The Fat Vow

always robed — the whole faction rides in context, every turn

  1. Download faction-legio.md — the faction. (The creed, adeptus-machinae.md, is the human mindset; it need not ride in context.)
  2. Paste Legio into your agent's AGENTS.md / CLAUDE.md — it is the law your agent runs.
  3. That is the whole rite. No install; any tool that reads the file is bound.

invocable · /via_*

The Invocable Rite

robes on call — the law loads when a Via is declared

  1. Install the skills into a skill root (~/.agents/skills).
  2. Add the thin hook to your AGENTS.md so the faction is invoked at every charge.
  3. Declare a rite by command — /via_emendatio … — and it walks its Ritus.

The downloads are operational law — written for the agent to execute, no preamble, no lore. Take one vestment, not both: the Fat Vow and the hook carry the same faction, and an agent robed twice reads its law doubled.
