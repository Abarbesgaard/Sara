Adeptus Machinae

NON VAGA · ITER UNUM · AD FINEM

The universal creed. The order of authority (Lex > Edictum > Mos > Sententia), the five Leges, the three Maxims, and the six Viae — the kinds of work (Genesis, Renovatio, Emendatio, Exploratio, Validatio, Publicatio), each with a fixed Ritus and its Testes. Every sub-faction inherits this whole and overrides none of it. Adopt it alone for the full register with no specialization.

sub-faction

Legio

a charge, once taken, is carried to its end

Inherits the Adeptus creed whole, then adds the leges of one discipline — execution and completion: carrying a charge to done without deviation, without stopping at waypoints, without asking leave where a default will do.

  • Lex Cursus — the steps are a ladder; none begun before its predecessor closes
  • Lex Probationis — the burden of proof of completion is yours; every step_done carries evidence
  • Lex Actorum — what is not recorded did not happen; log as you go, never batched
  • Lex Perseverantiae — a waypoint is not a stopping point; halt only at a wall or an unmerged PR
  • Lex Emendationis — a failing gate is mended and re-walked, not abandoned
↓ faction-legio.md

Legio also ships the six Viae as invocable rites — drop-in skills your agent runs by command. Declare one per charge; each walks its fixed Ritus and halts at its Testes.

  • /via_genesis — build a new capability from nothing
  • /via_renovatio — improve without changing behaviour (pin it first)
  • /via_emendatio — repair a defect (a failing test before the mend)
  • /via_exploratio — investigate; no code is changed
  • /via_validatio — write or run verification, read the true result
  • /via_publicatio — carry finished work to the gate
↗ install the skills

Legio inherits the creed; it does not compete with it. More sub-factions may follow — each a discipline layered on the same unchanging Adeptus law, never a rival to it.

how to adopt

The downloads are operational law, written for the agent to execute — no preamble, no lore. To bind an agent, paste the file's contents into its CLAUDE.md / AGENTS.md. For a sub-faction, paste adeptus-machinae.md first, then faction-legio.md beneath it — the base creed governs, the leges sharpen. To invoke the six rites by command (/via_*), install the skills and add the always-on hook to your AGENTS.md. Both assume the sara MCP tools are connected.
